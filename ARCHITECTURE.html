1. System Overview

Smart Travel Planner is a full-stack web application that helps users find travel destinations based on budget, temperature preferences, and travel type. The system includes advanced features like cost calculation, hotel booking, itinerary generation, reviews, and an admin dashboard for managing users and bookings.

Key Objectives

  • Budget-Aware Search: Find destinations within user's budget constraints
  • Multi-Factor Filtering: Search by temperature, distance, budget category, and travel type
  • Comprehensive Cost Calculation: Break down costs across travel, accommodation, food, and activities
  • Itinerary Generation: Auto-generate travel plans for 3-14 days
  • Community Reviews: User ratings and reviews for destinations and hotels
  • Admin Management: View all users, bookings, and system statistics
  • Group Travel Support: Split payments among friends for group trips

4. Core Features

User Authentication & Authorization

  • User Registration: New users register with email and password, automatically marked as non-admin (is_admin=FALSE)
  • User Login: JWT token-based authentication with 24-hour expiration
  • Admin Account: Default admin credentials (admin/admin) for system management
  • Role-Based Access Control: Different permissions for admin vs regular users
  • Password Security: BCrypt encryption for password storage

Destination Search & Discovery

  • Multi-Factor Filtering: Search by budget, temperature, distance, travel type
  • Budget Categories: Economy, Standard, Premium, Luxury
  • Travel Types: Adventure, Family, Couple, Business, Solo, Nature
  • Temperature Preferences: Cold, Mild, Hot, Tropical
  • Sample Destinations: 10+ pre-loaded destinations (Paris, Tokyo, Bali, etc.)
  • Search History: Track user searches for personalized recommendations

Hotel Management & Booking

  • Hotel Database: 12+ hotels per major destination with varying prices
  • Hotel Filtering: Filter by price, rating, amenities
  • Booking Management: Create, view, update booking status (Pending, Confirmed, Cancelled, Completed)
  • Price Tracking: Real-time price updates for hotels
  • Availability Checking: Real-time hotel availability status

Cost Calculator

  • Multi-Category Breakdown:
    • Travel (flights/transportation)
    • Accommodation (hotel)
    • Food (meals)
    • Activities (tours, attractions)
    • Miscellaneous
  • Budget Estimation: Intelligent estimation based on destination and travel type
  • Dynamic Updates: Calculate total cost based on travel dates
  • Cost Tracking: Store cost breakdown for each booking

Itinerary Generation

  • Auto-Generation: Generate daily itineraries for 3-14 day trips
  • Package Types: Family, Solo, Couple, Adventure
  • Day-by-Day Planning: Detailed activities for each day
  • Dynamic Customization: Users can modify generated itineraries

Reviews & Ratings

  • 5-Star Rating System: Users rate destinations and hotels
  • Review Types: Destination reviews and hotel reviews
  • Community Feedback: Users share experiences and recommendations
  • Helpful Sorting: Most helpful reviews highlighted first

Group Travel Support

  • Payment Splitting: Split trip costs among group members
  • Expense Tracking: Track who owes whom in group trips
  • Settlement Management: Mark payments as settled

Admin Dashboard

  • User Management: View all registered users and details
  • Booking Management: View ALL bookings from ALL users
  • Booking Status Updates: Change booking status (confirm, cancel, complete)
  • System Statistics:
    • Total users
    • Total revenue
    • Booking breakdown by status
    • Average booking value
  • Dashboard Summary: Quick overview with recent bookings

Additional Features

  • Emergency & Safety: Nearby hospitals, police stations, SOS contacts
  • Traditional Foods: Suggestions for local cuisine at each destination
  • Travel Tips: Destination-specific information (snow gear, entry passes, etc.)
  • Best Time to Visit: Seasonal recommendations
  • Cheapest Routes: Transportation cost comparison

6. REST API Specification

The API is documented with Swagger/OpenAPI at: http://localhost:8080/swagger-ui.html

Authentication Endpoints

POST /api/auth/register

Register new user account

POST /api/auth/login

Authenticate user and receive JWT token

Destination Endpoints

GET /api/destinations

List all destinations

GET /api/destinations/{id}

Get destination details with hotels and reviews

POST /api/destinations/search

Search destinations with filters (budget, temperature, travel_type)

Hotel Endpoints

GET /api/hotels

List all hotels with pagination

GET /api/hotels/{id}

Get hotel details including reviews and ratings

GET /api/hotels/destination/{destinationId}

Get all hotels for specific destination

Booking Endpoints

POST /api/bookings

Create new booking

GET /api/bookings/{id}

Get booking details

GET /api/bookings/user/{userId}

Get all bookings for current user

PUT /api/bookings/{id}

Update booking details

Cost Calculator Endpoints

POST /api/cost-calculator/estimate

Calculate cost breakdown for destination and dates

Review Endpoints

POST /api/reviews

Create review for destination or hotel

GET /api/reviews/destination/{destinationId}

Get all reviews for destination

GET /api/reviews/hotel/{hotelId}

Get all reviews for hotel

Admin Endpoints (Admin Only)

GET /api/admin/users

List all users in system

GET /api/admin/users/{id}

Get specific user details including bookings

GET /api/admin/bookings

KEY FEATURE: Get ALL bookings from ALL users

GET /api/admin/bookings/{id}

Get specific booking details

GET /api/admin/bookings/user/{userId}

Get all bookings for specific user

PUT /api/admin/bookings/{id}/status

Update booking status (confirm, cancel, complete)

GET /api/admin/stats

Get system statistics and analytics

GET /api/admin/dashboard

Get admin dashboard summary with recent bookings

7. Authentication & Security

JWT Token Authentication

  • Token Format: Bearer tokens in Authorization header
  • Expiration: 24 hours (86,400,000 milliseconds)
  • Secret Key: Configured in application.properties
  • Claims: Includes user ID and role information

Password Security

  • Encryption: BCrypt with strength factor 10
  • Storage: Only hashed passwords stored in database
  • Validation: Password requirements enforced on registration

Role-Based Access Control (RBAC)

ROLES: ├── ADMIN │ ├── Can view all users │ ├── Can view all bookings │ ├── Can update booking status │ ├── Can view system statistics │ └── Can access admin dashboard │ └── USER ├── Can register and login ├── Can search destinations ├── Can view hotels and prices ├── Can create bookings ├── Can view own bookings ├── Can create reviews ├── Cannot view other users' data └── Cannot access admin features

Security Features

  • CORS Configuration: Restricted to http://localhost:4200 and http://localhost:3000
  • Spring Security: Protects all endpoints with authentication checks
  • Input Validation: All user inputs validated at controller and service level
  • SQL Injection Prevention: Uses JPA parameterized queries
  • HTTPS Recommended: For production deployment
Important: The default admin credentials (admin/admin) should be changed in production environments.

8. Deployment & Startup

Prerequisites

  • ✅ Docker (for MySQL database)
  • ✅ Java 17+ (for Spring Boot backend)
  • ✅ Maven 3.8+ (for building backend)
  • ✅ Node.js 18+ (for Angular frontend)

One-Command Startup

Mac/Linux

chmod +x start-all.sh ./start-all.sh

Windows

Double-click start-all.bat or in Command Prompt: start-all.bat

What the Startup Script Does

Step 1: MySQL Database

• Starts MySQL 8.0 in Docker
• Creates database and user
• Imports schema
• Loads sample data
• Verifies readiness

Step 2: Spring Boot Backend

• Runs Maven build
• Compiles Java source code
• Starts on port 8080
• Initializes database connections
• Verifies health check

Step 3: Angular Frontend

• Installs npm dependencies
• Starts dev server on 4200
• Watches for file changes
• Compiles TypeScript
• Opens in browser

Docker Compose Alternative

For containerized deployment, use Docker Compose:

docker-compose up

This starts all three services (MySQL, Backend, Frontend) in containers with proper networking and health checks.

Stopping Services

With Script

Press Ctrl+C in the terminal running start-all.sh

Manual Cleanup

# Stop MySQL docker stop smart-travel-mysql docker rm smart-travel-mysql # Kill Backend and Frontend pkill -f "mvn spring-boot:run" pkill -f "ng serve"
✅ Verified Services: After successful startup, you should see:
  • MySQL listening on localhost:3306
  • Backend responding on localhost:8080/actuator/health
  • Frontend accessible at localhost:4200
  • Default admin login working (admin/admin)
