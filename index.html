Spring Boot 3.2 - A Java framework for server logic. It handles calculations and business rules, like a restaurant kitchen.

Database (Memory)

MySQL - A database for storing information. It's like a filing cabinet that stores all trip and hotel data.

TypeScript - A safer version of JavaScript. Like writing with better grammar rules.

Language: Backend

Java 17 - A powerful programming language. Like the engine that powers everything behind the scenes.

Build Tools

Maven & Angular CLI - Tools that compile and package the code, like building a car assembly line.

🌟Main Features Explained Simply

Browse amazing places to visit. Filter by budget (how much money you want to spend), interests (what you like to do), and ratings (what others think about the place).

Find and compare hotels in your chosen destination. See prices, amenities (like WiFi, swimming pool), and ratings from other travelers.

Automatically calculate how much your entire trip will cost. Get a breakdown of food, hotels, and activities.

Plan your trip day-by-day. Set activities, meals, and sightseeing for each day of your trip.

Discover traditional food and local restaurants. Filter meals based on dietary preferences.

⭐ Reviews & Ratings

Read what other travelers think about destinations. Write and share your own travel experiences.

📚Beginner's Guide: How It All Works

1

User Opens Website

You visit the website in your browser. The browser loads the Angular app (Frontend).

What's happening: JavaScript code runs in your browser to show the website.

2

Frontend Sends Request

You search for destinations. The Frontend sends a request to the Backend (like sending a letter).

Frontend says: "Give me all destinations in Goa with budget $500"
3

Backend Processes Request

The Backend receives the request. It uses business logic (Java code) to figure out what data to fetch.

Example: Filter destinations where price ≤ $500 and location = "Goa"

4

Database Lookup

The Backend asks the Database for matching destinations. The Database (MySQL) searches its tables.

SELECT * FROM destinations WHERE price <= 500 AND location='Goa'
5

Data Returns

The Database returns the matching data. The Backend formats it (JSON format) and sends it back to Frontend.

{ "destinations": [ {"name": "Beach Resort", "price": 450, "rating": 4.5}, {"name": "Hill Station", "price": 400, "rating": 4.8} ] }
6

Frontend Shows Results

The Frontend receives the data and displays it beautifully on your screen. You see hotels, prices, ratings!

What you see: A nice, colorful list of destinations you can click on.

🔑Key Concept: Frontend

The Frontend is the part you interact with:

  • What you see in your browser
  • Buttons, forms, search boxes
  • Uses Angular (JavaScript framework)
  • Runs on your computer/phone
  • Communicates with Backend via API

⚙️Key Concept: Backend

The Backend is the hidden logic:

  • Runs on a server (remote computer)
  • Processes business logic
  • Handles calculations & rules
  • Uses Java & Spring Boot
  • Provides data via REST API

💾Key Concept: Database

The Database is the memory:

  • Stores all trip information
  • Stores user accounts
  • Stores hotels, reviews, ratings
  • Uses MySQL (SQL database)
  • Organized in tables (like Excel)

🌐What is REST API?

REST API is how Frontend talks to Backend. Think of it like a restaurant:

  • API = Menu: Shows what requests you can make
  • GET: "Hey Backend, GET me information about all destinations"
  • POST: "Hey Backend, create a new trip for me"
  • PUT: "Hey Backend, update my trip details"
  • DELETE: "Hey Backend, delete my review"

Example API call:

GET /api/destinations?budget=500 → Returns all destinations under $500 POST /api/trips → Creates a new trip GET /api/hotels/5 → Gets details of hotel with ID 5

📊12 Database Tables Explained

The database has 12 tables (like 12 spreadsheets):

  • Users: All registered users and their profiles
  • Destinations: All travel locations (Goa, Manali, Kerala, etc.)
  • Hotels: Hotel information with prices and amenities
  • Trips: User trips/bookings
  • ItineraryDay: Day-by-day trip plans
  • Activities: Things to do each day
  • Meals: Meal plans for each day
  • Reviews: Reviews written by users
  • SafetyAlerts: Emergency contacts and safety info
  • TraditionalFood: Local cuisine information
  • TripHotel: Connects trips to hotels
  • TripShare: Trip sharing between friends

🚀How to Run This Project (For Beginners)

A

Prerequisites (Install These First)

Before running the project, you need to install:

  • Java 17+: Programming language for Backend
  • Node.js 18+: Runtime for JavaScript/Frontend
  • MySQL 8.0+: Database
  • Maven 3.6+: Tool to build Java project
B

Setup Database

Create MySQL database and import the schema:

1. Open MySQL Workbench or command line 2. Run: source Database/schema.sql 3. This creates tables and sample data
C

Start Backend Server

Run the Spring Boot application:

cd Backend mvn spring-boot:run The server starts on http://localhost:8080
D

Start Frontend

Run the Angular development server:

cd Frontend/smart-travel-planner npm install ng serve Visit http://localhost:4200 in your browser
E

Test the App

Now you should see:

  • ✅ Beautiful website with navigation
  • ✅ List of destinations
  • ✅ Hotel search functionality
  • ✅ Trip planning features
  • ✅ Sample data loaded
