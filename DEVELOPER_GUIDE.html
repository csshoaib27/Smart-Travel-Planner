📐 System Architecture

Overview

Smart Travel Planner follows a three-tier architecture:

Presentation Layer (Frontend)
Angular 17
- Responsive UI
- Client-side routing
- Form validation
- State management with RxJS
Application Layer (Backend)
Spring Boot 3.1
- REST API endpoints
- Business logic
- JWT authentication
- Data validation
Data Layer
MySQL 8.0
- Relational database
- Data persistence
- Transactional integrity
- Indexing for performance

Data Flow

Client (Angular)
     ↓↑ HTTP/REST
API Server (Spring Boot)
     ↓↑ JDBC
Database (MySQL)

Key Concepts

1. JWT Authentication Flow

Process:
  1. User login with username/password
  2. Server validates credentials
  3. Server generates JWT token
  4. Client stores token
  5. Client includes token in future requests
  6. Server validates token before processing

2. Service Layer Pattern

Each service handles business logic for a specific domain:

  • AuthService - User authentication and authorization
  • DestinationService - Destination management
  • HotelService - Hotel management
  • CostCalculatorService - Trip cost calculations
  • BookingService - Booking management

3. Repository Pattern

@Repository
public interface UserRepository extends JpaRepository<User, Integer> {
    Optional<User> findByUsername(String username);
    Optional<User> findByEmail(String email);
    boolean existsByUsername(String username);
}

Key Concepts

1. Services & Dependency Injection

// Define service
@Injectable({
  providedIn: 'root'
})
export class ApiService {
  constructor(private http: HttpClient) { }

  getDestinations(): Observable<any> {
    return this.http.get(`${this.baseUrl}/destinations`);
  }
}

// Inject in component
export class DestinationComponent {
  constructor(private apiService: ApiService) { }

  ngOnInit() {
    this.apiService.getDestinations().subscribe(
      data => this.destinations = data
    );
  }
}

2. Reactive Forms

export class LoginComponent {
  loginForm: FormGroup;

  constructor(private fb: FormBuilder) {
    this.loginForm = this.fb.group({
      username: ['', [Validators.required]],
      password: ['', [Validators.required, Validators.minLength(6)]]
    });
  }

  login() {
    if (this.loginForm.valid) {
      this.authService.login(this.loginForm.value).subscribe(...);
    }
  }
}

3. JWT Interceptor

Automatically adds JWT token to all HTTP requests:

@Injectable()
export class JwtInterceptor implements HttpInterceptor {
  constructor(private authService: AuthService) { }

  intercept(req: HttpRequest<any>, next: HttpHandler) {
    const token = this.authService.getToken();
    if (token) {
      req = req.clone({
        setHeaders: {
          Authorization: `Bearer ${token}`
        }
      });
    }
    return next.handle(req);
  }
}

🗄️ Database Design

Core Tables

Table Purpose Key Columns
users User accounts user_id, username, email, password, is_admin
destinations Travel locations destination_id, name, country, budget_category, travel_type
hotels Hotel properties hotel_id, destination_id, name, price_per_night
bookings Hotel reservations booking_id, user_id, hotel_id, check_in_date, total_price
itineraries Trip plans itinerary_id, user_id, start_date, end_date, package_type
reviews User reviews review_id, user_id, destination_id/hotel_id, rating, content

Users (1) ────────→ (M) Itineraries
Users (1) ────────→ (M) Reviews

Destinations (1) ──→ (M) Hotels
Destinations (1) ──→ (M) Reviews
Hotels (1) ────────→ (M) Bookings
Hotels (1) ────────→ (M) Reviews

Itineraries (1) ───→ (M) ItineraryDays
Bookings (1) ──────→ (M) PaymentSplits

Sample Queries

-- Find top-rated hotels in a destination
SELECT h.*, AVG(r.rating) as avg_rating
FROM hotels h
LEFT JOIN reviews r ON h.hotel_id = r.hotel_id
WHERE h.destination_id = 1
GROUP BY h.hotel_id
ORDER BY avg_rating DESC;

-- Get user's bookings with details
SELECT b.*, h.name as hotel_name, d.name as destination_name
FROM bookings b
JOIN hotels h ON b.hotel_id = h.hotel_id
JOIN destinations d ON b.destination_id = d.destination_id
WHERE b.user_id = ?
ORDER BY b.booking_date DESC;

Destination Endpoints

GET /destinations

Get all destinations

GET /destinations/search

Search destinations with filters

Query Parameters:
- country: string (optional)
- travelType: Nature|Adventure|Budget|Luxury|Cultural|Beach|Mountain
- budgetCategory: Budget|Mid-Range|Luxury
- minRating: number (optional)

Example: /destinations/search?country=France&budgetCategory=Luxury

Hotel Endpoints

GET /hotels/destination/{destinationId}

Get hotels in a destination

GET /hotels/search

Search hotels with price filters

Query Parameters:
- destinationId: number (required)
- minPrice: number (optional)
- maxPrice: number (optional)

Example: /hotels/search?destinationId=1&minPrice=50&maxPrice=200

🚀 Deployment Guide

Prerequisites

  • Docker and Docker Compose
  • AWS/GCP/Azure account (for cloud deployment)
  • Git for version control
  • SSL certificate (for HTTPS)

Docker Deployment

version: '3.8'

services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: smart_travel_db
    ports:
      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql

  backend:
    build: ./backend
    depends_on:
      - mysql
    environment:
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/smart_travel_db
    ports:
      - "8080:8080"

  frontend:
    build: ./frontend
    ports:
      - "4200:4200"
    depends_on:
      - backend

volumes:
  mysql_data:

AWS Deployment

Architecture:
  1. RDS MySQL for database
  2. Elastic Beanstalk for backend
  3. S3 + CloudFront for frontend

❓ Frequently Asked Questions

How do I add a new feature?

  1. Create feature branch: git checkout -b feature/new-feature
  2. Backend: Create model, repository, service, and controller
  3. Frontend: Create component and add routing
  4. Test thoroughly
  5. Submit pull request

How do I add a new destination?

Use the admin dashboard or API:

POST /api/destinations
{

  "temperatureAvg": 15,

}

How do I debug the backend?

  • Check logs: tail -f logs/app.log
  • Use Spring Boot actuator: http://localhost:8080/actuator
  • Enable debug logging in application.properties
  • Use IDE debugger with breakpoints

How do I reset the database?

mysql -u root -p
DROP DATABASE smart_travel_db;
SOURCE database/database_schema.sql;
SOURCE database/sample_data.sql;

What are the default admin credentials?

Username: admin
Password: admin
⚠️ Change these in production!

How do I handle CORS errors?

Check and update CORS configuration in:

  • application.properties (Backend)
  • SmartTravelApp.java (CORS bean)
  • Ensure frontend URL is whitelisted
