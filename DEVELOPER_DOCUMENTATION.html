1️⃣ Project Overview

Project Description

Smart Travel Planner is a full-stack web application designed to help users discover, plan, and book travel destinations based on their budget, climate preferences, and travel interests. The platform provides intelligent recommendations, cost calculation, itinerary generation, and a community review system.

Key Objectives

  • One-Command Startup: All services (MySQL, Spring Boot, Angular) start with a single command
  • Easy User Registration: New users automatically get is_admin=FALSE in database
  • Admin Capabilities: Admin users can view ALL user bookings from all users in the system
  • Production Ready: Security, error handling, logging implemented throughout
  • Developer Friendly: Well-documented code with clear separation of concerns
✅ Current Status: Project completed and tested. All services integrating and responding correctly. One-command startup fully functional.

Three-Tier Architecture

Presentation Layer (Frontend)

Angular 17 application running in user's browser. Handles all UI, user interactions, and client-side validation. Communicates with backend via REST API calls using JWT tokens for authentication.

Business Logic Layer (Backend)

Spring Boot REST API handling all business logic, data validation, and security. Implements role-based access control (Admin vs User). Exposes 40+ RESTful endpoints documented via Swagger.

Data Access Layer (Database)

MySQL database with relational schema. Hibernate ORM manages database interactions, preventing SQL injection and handling transactions. Database includes 100+ sample records across multiple tables.

User Entity (JPA Model)

User.java - Database Model 
@Entity
@Table(name = "users")
public class User {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(unique = true, nullable = false)
    private String email;

    @Column(nullable = false)
    private String password;      // Encrypted with BCrypt

    @Column(nullable = false)
    private String name;

    @Column(name = "is_admin")
    private Boolean isAdmin = false;  // Key feature: new users get FALSE

    @CreationTimestamp
    @Column(nullable = false, updatable = false)
    private LocalDateTime createdAt;

    @UpdateTimestamp
    @Column(nullable = false)
    private LocalDateTime updatedAt;

    // Relationships
    @OneToMany(mappedBy = "user", cascade = CascadeType.ALL)
    private List bookings;

    @OneToMany(mappedBy = "user", cascade = CascadeType.ALL)
    private List reviews;
}

User Service (Business Logic)

UserService.java - Key Methods 
@Service
public class UserService {

    // Register new user (is_admin defaults to FALSE)
    public User registerUser(RegisterRequest request) {
        User user = new User();
        user.setEmail(request.getEmail());
        user.setPassword(passwordEncoder.encode(request.getPassword()));
        user.setName(request.getName());
        user.setIsAdmin(false);  // ← Important: New users are NOT admins
        return userRepository.save(user);
    }

    // Get current user
    public User getCurrentUser() {
        String currentUsername = SecurityContextHolder
            .getContext()
            .getAuthentication()
            .getName();
        return userRepository.findByEmail(currentUsername)
            .orElseThrow(() -> new ResourceNotFoundException("User not found"));
    }

    // Admin feature: Get all users
    @PreAuthorize("hasRole('ADMIN')")
    public List getAllUsers() {
        return userRepository.findAll();
    }
}

Security Configuration

SecurityConfig.java - Spring Security Setup 
@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .csrf().disable()
            .cors().and()
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/auth/**").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated()
            )
            .addFilterBefore(
                new JwtAuthenticationFilter(),
                UsernamePasswordAuthenticationFilter.class
            );

        return http.build();
    }

    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();  // BCrypt for password hashing
    }
}

Key Services

AuthService - Authentication

auth.service.ts 
@Injectable({providedIn: 'root'})
export class AuthService {

    constructor(private http: HttpClient) {}

    // Register new user
    register(userData: any): Observable {
        return this.http.post('/api/auth/register', userData);
    }

    // Login user
    login(email: string, password: string): Observable {
        return this.http.post('/api/auth/login', { email, password })
            .pipe(
                tap(response => {
                    // Store JWT token in localStorage
                    localStorage.setItem('token', response.token);
                    localStorage.setItem('user', JSON.stringify(response.user));
                }),
                catchError(error => {
                    console.error('Login failed', error);
                    return throwError(error);
                })
            );
    }

    // Get current user
    getCurrentUser(): any {
        const userStr = localStorage.getItem('user');
        return userStr ? JSON.parse(userStr) : null;
    }

    // Check if user is admin
    isAdmin(): boolean {
        const user = this.getCurrentUser();
        return user && user.isAdmin === true;
    }

    // Logout user
    logout(): void {
        localStorage.removeItem('token');
        localStorage.removeItem('user');
    }

    // Get JWT token
    getToken(): string | null {
        return localStorage.getItem('token');
    }

    // Check if logged in
    isAuthenticated(): boolean {
        return !!this.getToken();
    }
}

JWT Interceptor

jwt.interceptor.ts - Auto Token Injection 
@Injectable()
export class JwtInterceptor implements HttpInterceptor {

    constructor(private authService: AuthService) {}

    intercept(
        req: HttpRequest,
        next: HttpHandler
    ): Observable> {

        // Get JWT token from storage
        const token = this.authService.getToken();

        if (token) {
            // Clone request and add Authorization header
            req = req.clone({
                setHeaders: {
                    Authorization: `Bearer ${token}`
                }
            });
        }

        return next.handle(req);
    }
}

Auth Guard

auth.guard.ts - Protected Routes 
@Injectable({providedIn: 'root'})
export class AuthGuard implements CanActivate {

    constructor(
        private authService: AuthService,
        private router: Router
    ) {}

    canActivate(
        route: ActivatedRouteSnapshot,
        state: RouterStateSnapshot
    ): boolean {

        if (this.authService.isAuthenticated()) {
            return true;
        }

        // Redirect to login if not authenticated
        this.router.navigate(['/login']);
        return false;
    }
}

Component Example: Login

login.component.ts 
@Component({
    selector: 'app-login',
    templateUrl: './login.component.html',
    styleUrls: ['./login.component.css']
})
export class LoginComponent implements OnInit {

    loginForm: FormGroup;
    loading = false;
    submitted = false;

    constructor(
        private formBuilder: FormBuilder,
        private authService: AuthService,
        private router: Router
    ) {
        // Redirect to home if already logged in
        if (this.authService.isAuthenticated()) {
            this.router.navigate(['/dashboard']);
        }
    }

    ngOnInit() {
        this.loginForm = this.formBuilder.group({
            email: ['', [Validators.required, Validators.email]],
            password: ['', Validators.required]
        });
    }

    get f() {
        return this.loginForm.controls;
    }

    onSubmit() {
        this.submitted = true;

        if (this.loginForm.invalid) {
            return;
        }

        this.loading = true;

        this.authService.login(
            this.f['email'].value,
            this.f['password'].value
        ).subscribe({
            next: (response) => {
                // Successfully logged in
                if (response.user.isAdmin) {
                    this.router.navigate(['/admin/dashboard']);
                } else {
                    this.router.navigate(['/dashboard']);
                }
            },
            error: (error) => {
                console.error('Login failed', error);
                this.loading = false;
            }
        });
    }
}

Core Tables

1. users Table

User Accounts with Admin Flag 
CREATE TABLE users (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    email VARCHAR(255) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,  -- BCrypt encrypted
    name VARCHAR(255) NOT NULL,
    is_admin BOOLEAN DEFAULT FALSE,  -- ← Admin flag (default FALSE)
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_email (email)
);

Key Features:

  • is_admin defaults to FALSE for new users
  • Passwords encrypted with BCrypt
  • Email unique constraint prevents duplicates
  • Timestamps for auditing

2. destinations Table

Travel Destinations 
CREATE TABLE destinations (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(255) NOT NULL,
    description TEXT,

    climate VARCHAR(50),              -- warm, mild, cold

3. hotels Table

Accommodations (120+ entries) 
CREATE TABLE hotels (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(255) NOT NULL,
    destination_id BIGINT NOT NULL,
    description TEXT,
    price_per_night DECIMAL(10, 2),

4. bookings Table

User Trip Reservations

Password Security

BCrypt Password Hashing

All passwords are encrypted using BCrypt, a secure one-way hashing algorithm with salt.

  • Never stored in plain text: Passwords are irreversibly hashed
  • Salt included: Each password is salted, preventing rainbow table attacks
  • Slow algorithm: BCrypt is intentionally slow to resist brute-force attacks
  • Strength factor: Set to 10, making it computationally expensive to crack
BCrypt Example 
Original Password:     "MyPassword123"
BCrypt Hash:           "$2a$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcg7b3XeKeSmMGZpd7PcpEcp5TO"

When user logs in:
1. User provides: "MyPassword123"
2. System hashes it with same salt
3. Compare hashes
4. If match: Authentication successful
5. If no match: Authentication failed

Security Configuration

Spring Security Setup 
@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            // Disable CSRF for stateless API
            .csrf().disable()

            // Enable CORS for localhost:4200
            .cors().and()

            // Authorization rules
            .authorizeHttpRequests(authz -> authz
                // Public endpoints
                .requestMatchers("/api/auth/register", "/api/auth/login").permitAll()
                .requestMatchers("/api/destinations", "/api/hotels").permitAll()

                // Admin only endpoints
                .requestMatchers("/api/admin/**").hasRole("ADMIN")

                // All other endpoints require authentication
                .anyRequest().authenticated()
            )

            // Add JWT filter
            .addFilterBefore(
                new JwtAuthenticationFilter(),
                UsernamePasswordAuthenticationFilter.class
            )

            // Disable session (stateless)
            .sessionManagement()
            .sessionCreationPolicy(SessionCreationPolicy.STATELESS);

        return http.build();
    }

    @Bean
    public PasswordEncoder passwordEncoder() {
        // BCrypt with strength 10
        return new BCryptPasswordEncoder(10);
    }
}

🔟 Feature Implementation

1. User Registration & Authentication

Implementation: New users register through /api/auth/register endpoint. System automatically sets is_admin=FALSE, ensuring regular users cannot elevate themselves.

2. Destination Search with Filters

Implementation: POST /api/destinations/search accepts budget, climate, and travel type filters. Returns relevant destinations using database queries.

3. Hotel Browsing & Booking

Implementation: 120+ hotels stored in database. Users can view hotel details, prices, and availability. Bookings create records in bookings table linking users, destinations, and hotels.

4. Cost Calculator

Implementation: cost_breakdown table tracks expenses in categories (travel, stay, food, activities). Calculates total cost for bookings.

5. Itinerary Generation

Implementation: Users specify duration. System generates day-by-day itinerary stored in itineraries table.

6. Community Reviews (5-Star)

Implementation: reviews table stores user ratings (1-5) and comments. Displayed with destinations showing average ratings.

7. Admin Dashboard

Implementation: AdminController provides endpoints to view all users, all bookings, and system statistics.

8. Admin View All User Bookings (Key Feature)

Implementation: GET /api/admin/bookings returns all bookings from all users in system. Protected with @PreAuthorize("hasRole('ADMIN')").

9. Group Cost Splitting

Implementation: payment_splits table tracks shared expenses. Each user's share calculated and stored.

10. Search History Tracking

Implementation: search_history table logs all searches with criteria and result count for user reference.
